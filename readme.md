# Overview

{This program was created to help me start learning the Kotlin language.  
This program is a hangman game where the user tries to guess a word before guessing wrong letters too many times.}

# Development Environment

{This program was written using Visual Studio Code}
{The program is written in the Kotlin langauge.
The program uses the following libraries:
kotlin.system.exitProcess
java.io.File

and these for unit testing:

org.junit.jupiter.api.Assertions.assertFalse

}
